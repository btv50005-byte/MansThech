## 🛠️ Personnalisation Simple pour Débutant

### 1. Photo de profil
- Votre photo est configurée dans `images/photo.jpg` (également à la racine `photo.jpg`) et affichée dans le cercle avec un effet lumineux néon cyan/bleu. Pour la mettre à jour, remplacez simplement `images/photo.jpg`.

### 2. Remplacer ou modifier le logo
- Remplacer simplement le fichier `images/logo.png` par votre propre image de logo.

### 3. Modifier les liens de vos projets
- Dans `js/script.js`, modifiez les propriétés `liveLink` et `githubLink` de chaque projet (de 1 à 8).

## 🚀 Mise en Ligne Gratuite sur GitHub Pages

1. Créez un compte sur [GitHub.com](https://github.com).
2. Créez un dépôt public nommé `portfolio-mansour`.
3. Téléversez l'ensemble des fichiers (`index.html`, `css/`, `js/`, `images/`, `README.md`).
4. Dans **Settings** > **Pages**, choisissez la branche `main` et cliquez sur **Save**.
5. Votre site sera instantanément en ligne avec une adresse sécurisée HTTPS !
